# Package capabilities

Generated by `npm run capabilities:generate`. Counts describe inspected source/plugin directories, not observed native-host execution. ZIP counts below are packaging expectations derived from source; built ZIP contents require separate artifact validation.

| Delivery | Instructions | Command wrappers | Registered hooks | Assurance and limits |
|---|---:|---:|---:|---|
| Source checkout | 33 | 13 in plugin | 2 in plugin | Local commit enforcement requires explicit repository enrollment; protected CI must verify its own candidate. |
| Claude plugin | 33 | 13 | 2 | SessionStart/Stop require Node and a supporting Claude host. Run /oc-enroll successfully per repository for Git commit verification; installation alone does not activate it. |
| Skills ZIP / copied Codex skills | 33 expected in combined ZIP; 1 expected per-skill ZIP | 0 | 0 | Instructions and bundled references only. No host hook registration or repository-level runtime is supplied by this delivery mode. |
| Portable local runtime | 33 | npm CLI entry points | 0 | Private local runtime artifact; no host hook registration. Entry files must be present, dependencies/loadability require the separate artifact smoke test. Commit verification requires explicit target enrollment. |
| Local MCP | Resource API | Protocol tools, not host slash wrappers | 0 | Project-local state and skill resources; filesystem locking and runtime dependencies must pass startup checks. No commit authority is conveyed by checkpoints. |
| Hosted MCP | Resource API | Protocol tools, not host slash wrappers | 0 | Remote resources and session state are advisory. No local filesystem or commit enforcement; server availability is not inspected here. |

Run `node scripts/capabilities.mjs --mode MODE --root ARTIFACT_ROOT` before configuring an install. Modes: source, claude-plugin, skills, local-mcp, hosted-mcp, runtime. The read-only diagnostic emits versioned JSON and exits 1 for missing/malformed required package files, 2 for invalid arguments. For skills mode, point at the directory containing skill folders. The diagnostic itself ships in the source checkout; it does not require installation or modify the inspected artifact. runtime_files reports entry-file presence only, not loadability. Host execution, Git enrollment, dependency availability and external-provider access require separate runtime checks.
