## MEDIUM

- **A-05** `opchain-evidence.yml:48-50`: the "independent" check runs the PR head's own verifier and `.bugcheck.json`, so a PR can rewrite its own gate. The skip is also gated on a `dependencies` label. Same label skip in this repo's `ci.yml:53` (**C-07**).
- **A-06 / C-02** `templates/deploy.mjs:94-104,201-207`: the ancestor guard fails open when `/api/health` is unreachable or challenged (Bot Fight Mode). The template also has no clean-tree check, unlike `scripts/deploy.mjs:241`.
- **A-07** `install-git-drivers.mjs:155-168`: composable snippets contain a bare `exit 0`, which ends the host hook early.
- **B-02** `route-dispatch.cjs:765-801`: any `/oc-*` token routes at p=1, including in negations. "do not run /oc-deploy prod yet" produced an invoke instruction in live mode.
- **B-03** `route-eval.mjs:742-748`: the report uses one flat `fits` bar, but the shipped router is tiered (0.6 for core, 0.9 for others). The runbook's thresholds can't be reproduced.
- **B-04** `route-eval.mjs:1016-1060`: explicit-mention outcomes inflate the Day-8 GO precision proxy.
- **B-05** `route-prompt.cjs:262-367`: up to about 9.5 s of synchronous git, `gh` and HTTPS work per prompt, even in shadow mode. The watchdog can't preempt `spawnSync`.
- **B-06** `session-state.cjs:341-346`: SessionStart runs the repo's own `scripts/check-release-tag.mjs` in any repo with a matching release checkpoint. That executes code from an untrusted clone.
- **C-01** `oc-deploy-ops/SKILL.md:311` vs `templates/deploy.mjs:197`: the skill says prod needs `--prod` and no env var. The template defaults to prod and accepts `<PROJECT>_PROD_GO=1`.
- **C-03** `templates/deploy.mjs:124-160`: the fallback raw JSON write replaces `next_actions` with `[]` and swallows a corrupt checkpoint.
- **C-04 / D-05** `orchestrator.md:196`, `oc-deploy-ops/SKILL.md:299`: `install-git-drivers --deploy-wrapper` is documented but doesn't exist.
- **C-05** `scripts/checkpoint.mjs:1174-1179`: `handoff` can't find `release-evidence.mjs` in consumer repos. Reproduced. This breaks the new default PR-evidence path.
- **C-06** `lib/release-evidence.mjs:65-67`: every evidence FAIL prints a ready-to-paste `handoff … --verdict PASS`, including for the pre-deploy audit policies.
- **C-08** `scripts/deploy.mjs:487`: the printed `gh pr create --body "…"` contains backticks, which execute when pasted.
- **D-04** `oc-bug-check/SKILL.md:431`, `oc-git-ops/SKILL.md:258`: `scripts/verify-candidate.mjs explain` is the wrong path in consumers. It is installed under `.git/opchain/commit-gate/<ver>/` or `.opchain/runtime/scripts/`.
- **D-06** `site/src/pages/install.astro:282,335` (plus glossary and security): unversioned docs for `--ci`, `--doctor`, the router and the new hooks, while every version stamp is 2.0.4. Must not deploy before the 2.1 tag.
- **D-07** `architecture.astro:1539`, `MobileArchitecture.astro:905`: rendered text "draft for 2.1, uncommitted".
- **D-08** `architecture.astro:1475-1541`: Jev rail SVG text renders at about 7–9 px on desktop (WCAG 1.4.4).
- **Checkpoint**: `handoff` defaults new files to `phase: "verify"`, which no skill declares. It is a warning today and will become an error once phases are strict.

## Recommended fix order

1. **D-01**: standardise the trailer on `Opchain-Bypass:` in the five skill passages. Text-only.
2. **A-02, A-01, A-08**: make pre-push fail closed on `rev-list` errors, and excuse rewrites only when the pre-rewrite commit has a PASS receipt or trailer.
3. **A-03, A-07**: separate the snippet marker from the managed marker, back up before overwriting, and remove bare `exit`.
4. **D-02, C-04/D-05, D-03, D-04, C-05**: either reword each phantom gate or wrong path to match EnforcementMap's honest status, or ship the script. Fix `handoff` resolution for `.opchain/runtime`.
5. **A-04, A-05, C-07, C-06**: make the CI-side claims honest, run the verifier from the base ref, gate the skip on the actor rather than the label, and stop printing self-approval commands for the audit policies.
6. **B-01, B-03, B-04**: fix route-eval before anyone reads Day-8 numbers.
7. **B-06, B-05, B-02**: SessionStart code-exec guard, prompt-hook latency, explicit-mention negation.
8. Template deploy guards (A-06/C-01/C-03), site copy (D-06–D-08), then the LOWs.
