# Handoff package fixture preparation

The retry-3 handoff refusal remains valid and unchanged: the documentary fixture
named `npm test` without providing a package, executable suite or Git history.
This change prepares a new successful-path exercise; it does not repair that
capture or establish fresh model acceptance.

`tests/fixtures/ow-handoff/package/input/larkspur-repo/` now supplies a
dependency-free order-processing subset with six executable tests, package
commands, a local artifact writer and accurate test/deploy/developer docs.
Unknown codes cannot reach invoice payloads; invalid quantities and duplicate
orders fail. The fixture is explicitly smaller than the fictional full system
described in inherited UAT/operator records. Its deployment commands write local
JSON examples and make no network requests.

`scripts/prepare-ow-handoff-package.mjs prepare <new-workspace>` layers those
inputs, removes inherited prior screens before exposing the workspace, creates
two isolated synthetic Git commits, runs the suite and writes an external
receipt. The receipt holds actual execution outputs/timestamps, input hashes,
the preparer hash and source-checkout ow-tools path/version probe. A workflow
definition is not presented as a hosted CI result. The model still must not run
repository-defined commands; it may cite the preparer's measured test result.

The scenario and synthetic session explicitly distinguish the user-stated
**2027-02-17** scenario date from the **2027-02-24** planned send date. No delivery,
read-through, transfer, signature or other missing approval is supplied by the
preparer. The local tool adapter is not public pin/install or installed-host
trigger evidence.

The `grade` mode makes a separate evaluator projection only after checking every
repository byte against the preparation receipt. It excludes only unchanged
preparer-owned `.git` metadata, which the existing text grader otherwise treats
as model writes. The external projection manifest records all raw/projected
hashes and every exclusion; no output text is repaired or normalized. Extra
model files remain graded. Changed repository files or Git metadata, symlinks,
existing destinations and projections inside the raw capture are refused.
