## New findings

### [F-026] Capture host names reach `--host-resolver-rules` without host-name validation

**Severity:** LOW · **Category:** security (argument grammar) · **Location:** `plugins/ow-tools/lib/capture.mjs:149-166`, `:364-367` (= posture SA-020)
**Problem:** `origin()` accepts any WHATWG host; `,`, `*`, `!`, `;`, `=`, `'`, `~` pass (whitespace doesn't). `hostRules` writes the host into a comma-separated rule list, so a resolvable name such as `a.example.com,exclude` yields an extra `EXCLUDE <checked address>` rule and `*` / `*.example.com` yield wildcard `MAP`s ahead of the catch-all. Every outcome still routes only to a checked address and the Fetch guard still blocks unlisted origins.
**Evidence:** `poc15-hostrules.mjs`: `--host-resolver-rules=MAP * 203.0.113.5 , MAP * ~NOTFOUND`.
**Fix:** in `origin()`, require `HOST` (`health.mjs:18`) or an IP literal; plants for `,` and `*`.

### [F-027] Concurrent runs on one profile: the second removes the first's production pending-wipe marker

**Severity:** LOW · **Category:** security (session at rest; concurrency) · **Location:** `plugins/ow-tools/lib/capture.mjs:650-657` (= posture SA-021)
**Problem:** no per-profile run lock; a second run's start deletes Chrome's `SingletonLock`, wipes and then (non-production) removes `.ow-tools-production-pending`. If the first, production, run is then SIGKILLed, the next run won't wipe what it left.
**Evidence:** `poc17-concurrent.mjs` (fake browser, fence on): marker present while A runs → gone after B → A SIGKILLed with no marker.
**Fix:** exclusive `.ow-tools-run.lock` (`openSync(…, "wx")`, pid inside, stale-pid takeover) before any clean, wipe or marker step; refuse with `profile-in-use`.

### [F-028] Secret-field name rule misses non-English, accented and leetspeak names

**Severity:** LOW · **Category:** security (heuristic) · **Location:** `plugins/ow-tools/lib/capture.mjs:47-95` (= posture SA-022)
**Problem / Evidence:** `secretName` returns false for `contraseña`, `Kennwort`, `senha`, `wachtwoord`, `lösenord`, `salasana`, `hasło`, `пароль`, `パスワード`, `p@ssword`, `pa55word`, "Enter the code we texted you"; no false positive on 20 ordinary names. `type=password`, `autocomplete` and the plan-value check still apply.
**Fix:** NFD accent folding before matching; a short multilingual stem list; `code` + `sent|texted|emailed` sequences.

## Checked and clean (round-3 changes)

- **`pinOrigins`** (`capture.mjs:594-620`): one lookup per name; every answer checked (`isLoopbackHost` / `isLinkLocalHost` cover IPv4, IPv6, mapped, translated, compatible, NAT64, 6to4); a resolver error or empty answer leaves no rule, so the name is `NOTFOUND`; one address pinned (first IPv4, else first), IPv6 bracketed. Test hosts are exempt only through `deps.testOrigins`, which the CLI never sets. poc16: 14 answer shapes behave as designed, including CNAME-to-loopback and private RFC 1918 (allowed by design for internal test environments).
- **No TOCTOU:** Chrome gets `MAP <name> <checked address>`, so it never resolves an allowed name; `MAP * ~NOTFOUND` covers everything else, including prefetch and secure DNS. IP-literal origins get `EXCLUDE` after the plan reader has refused loopback, link-local and special-purpose IPv6.
- **Fence and docs:** `defaultResolver` loads `node:dns` by dynamic import inside capture only; `sprint-t.test.js` pins that exactly (C25a holds for the hook and the no-network verbs). The manifest Network row and `help network` both name the lookup.
- **Signal handling:** handlers are added after launch and removed in `finally`; the handler kills the browser group, wipes, waits ≤ 2 s, wipes again, removes the marker and exits `128 + n`; running concurrently with the main `finally` is safe because both wipe before removing the marker. Unhandled terminating signals and uncaught exceptions leave the marker (fail-safe); SIGPIPE and SIGUSR1 don't end the process, which then reaches its own `finally`. `DEFAULT_TIMEOUT` 110 s sits under Claude Code's 120 s Bash timeout.
- **pandoc:** `gfm-…-yaml_metadata_block` in both readers; `raw_attribute`, `raw_tex`, `pandoc_title_block` off in pandoc 3.12.1 `gfm`; `imagesPandocReads` walks the whole document and uses a new reason `unchecked-image`; `withoutCode` stops an escaped backtick from hiding HTML or an image.
- **OSV:** per-package flags for every partial or odd reply; the file summary becomes attention when any flag is set. `cvss3Score` follows the 3.1 Roundup; unknown vectors stay `unknown` (never OK); `MAL-` first.
- **Lockfiles:** npm and yarn aliases are checked under the real package name only (the alias label never leaves); yarn key specs that are paths, git or URLs are classed local/private before `resolved` is read.
- **`.bugcheck.json`:** one exact-path, digest-pinned `secrets` exception (`sha256:770a5e84…5b211028`, matches the file). This round's reports contain no key material, so the exception can be removed when they're copied in.
