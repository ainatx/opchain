# S6 — Tenant-safe AI support service simulation

Six requested skill workflows were exercised against a small synthetic support service. This adds six skill-level coverage entries, with failed and partial outcomes retained. It does not demonstrate live agent behavior, production retrieval readiness, provider authenticity, approved design, or actual spending.

Candidate: `63bb189dabb7c98b2fd961f11de144925a6e9519`. Inputs, prepared local implementation, owner plans, checkpoints, and outputs are all under [evidence/s6](evidence/s6/coverage.json). The candidate product was not modified. No extra agents were delegated, no external endpoint was called, and no real credentials, approvals, deployments, or learned-rule activations were created.

## Release-relevant limitations

The corpus has seven synthetic snippets; fifty queries include correlated wording variants, not fifty independent production incidents. The lexical retriever deliberately stands in for unavailable vector infrastructure. No embeddings, reranker, real model, SDK agent loop, generative faithfulness judge, or cache usage were measured. The scripted agent trajectories test dispatch/termination contracts, not model judgment. The connector uses public fixture constants and memory-only single-process state; it does not certify distributed replay protection or actual retry timing. One prompt case ID says missing role while its actual input tests missing tenant; the detailed report identifies this labeling limitation and makes no role-validation claim.

The negative prompt comparison kept identical prompt and dataset bytes and changed the synthetic adapter's behavior. It demonstrates induced drift detection, not prompt optimization. Raw shipped runtime schemas do not carry synthetic provenance, so their surrounding scenario/transcript must remain attached. No real price was assumed; fixture prices and usage units are explicitly fictional.

A candidate documentation inconsistency was observed: `oc-cost-ops/SKILL.md` documents shipped npm commands and missing-baseline BLOCKED behavior, while its `references/budget-gates.md` still says no runner ships and describes a ceiling-only path without a baseline. Actual execution follows the skill contract and blocks. Reconcile that reference before release; it was not edited during simulation.

S6 supplies the requested six representative workflows. Production acceptance remains held by the failed retrieval thresholds, absent live evaluation/provider evidence, pending review gates, and the documented operational limits.
