# oc-update targeted audit

Source-mode follow-up: the updater now handles the authoring repository's
symlink layout using staged canonical generators, with no release download.
Twenty-one additional source tests and independent transaction review passed.
A source-snapshot guard gap for no-op/check results was fixed and independently
reproduced as closed. The real source-repo invocation returned current/verified
with telemetry, checkpoints, links, Git HEAD and clean working status preserved.

**Scope:** repo install/update and telemetry preservation. **Grade: B+ (8.5/10)**
for this isolated changeset. Older repository-wide audit findings remain open.

The existing website's directory-delete upgrade flow (`site/src/pages/install.astro:27`)
can delete unrelated skills before a download succeeds. Its replacement is prepared
in this silo, but the public website text remains a release-integration task; this
report does not describe the live site as fixed.

The existing archive missed the telemetry executable required by its instructions.
The candidate ships portable telemetry/checkpoint launchers and their canonical
runtimes, checks their synchronization, and updates installed instructions. Pack
dispatch instructions now have a bundled-metadata fallback in consumer repos.

The new updater validates release/file digests and paths, stages the intended
contents before writes, backs up prior files, verifies installation, and restores
on caught failures. It does not touch telemetry consent or checkpoints, including
when telemetry is enabled but unhealthy. Local backups and SQLite files have
narrow ignore rules. Tests cover failed recovery and malicious paths as well as
the happy path.

Independent review found four candidate issues (WAL side effects, symlinked CLI
dispatch, global-only routing, misleading check-only output). All four were fixed
and reverified; see [evaluation](../../sprints/repo-updater/eval.md) for evidence.

Residual release requirements: publish and smoke-test the matching HTTP assets;
integrate the 2.0 runtime dependency closure and new kits; validate the combined
36-skill artifact through actual supported agent hosts. HTTPS remains the publisher
trust boundary; content digests detect corruption and mixed releases, not a
compromised publisher. No global plugin cache or hook settings are updated here.
