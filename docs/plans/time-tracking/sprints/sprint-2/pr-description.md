## Summary

Turn normalized session events into overlap-safe daily ledger drafts, with model
pricing and verification. Internal work competes for time; autonomous-only blocks
bill zero; repeated drafts append nothing; approved or edited days preserve their
history and report derivation drift.

**Stacked on #569:** Sprint 1 is still open with green CI. This PR targets
`codex/time-tracking-sprint-1` to keep its diff scoped to Sprint 2. Merge Sprint 1
first, then rebase/retarget this PR onto main. Do not merge this PR into the Sprint 1
branch. A human supplies their own squash-merge sign-off.
