## Summary

Add the Sprint 1 local transcript collector and silent UserPromptSubmit hook.
Collection produces a sorted, de-duplicated event cache without retaining prompt
text, with a format canary that exposes unknown envelopes and producer versions.

Machine envelopes override human origin flags. Subagents attach to their parent
without adding human events; forks share UUID/message-ID de-duplication; queue
prompts count at enqueue time; hook timestamps supersede nearby transcript prompts.
Cursors support append, truncate, inode replacement and interrupted publication.
