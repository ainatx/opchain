# oc-time-ops spec audit (2026-09-26)

**Scope:** a design audit of `docs/plans/time-tracking/spec/`. There's no code
yet, so every assumption was tested against the real transcript corpus
(`~/.claude/projects`: 3,375 files, 367,256 lines, 2.1 GB). The probes were
throwaway Node and `jq` scripts, not committed.

**Verdict: it would not work as specified.** The overall architecture holds up:
a local collector, derived drafts, an append-only ledger and human approval. But
four core assumptions about the transcripts are false, and each one would
produce wrong bills. **Design grade: D+.**

**oc-bug-check on the working diff: PASS.** The diff is docs plus one checkpoint:
- `checkpoint:validate` reports 17 valid.
- `lint-internal-refs` is clean.
- No secrets.
- No code, so there were no tests to run.

## Findings

### C-1 · CRITICAL: the human-prompt classifier bills automated turns
**Evidence** (non-tool user text lines in main session files):

| Kind | Count |
|---|---:|
| Plain human text | ~1,000 |
| `<task-notification>` | 702 |
| `<ci-monitor-event>` | 103 |
| `<scheduled-task>` | 69 |
| `<system-reminder>` | 76 |
| `<local-command-stdout>` | 53 |
| Compaction summaries | 11 |

Claude Code's own `origin.kind:"human"` flag is also set on 69 scheduled-task
lines, 37 CI-monitor lines and 68 system-reminder lines. 173 lines have no
`origin` field at all.

**Root cause:** the spec assumed that a `user` line is a human. The harness
delivers automated wake-ups as user turns and labels them inconsistently.

**Impact:** in the block model a single misclassified line makes the whole
block billable. A scheduled task that runs overnight would bill its entire run.

### C-2 · CRITICAL: subagent work lives in separate files
**Evidence:**
- 3,118 of the 3,375 files are `<session>/subagents/*.jsonl`.
- Main session files contain 0 `isSidechain` lines.
- Subagents account for 51% of output plus cache-write tokens.

**Root cause:** the spec's event table models subagent lines as `isSidechain`
lines inside the main transcript. That's wrong.

**Impact:**
- Cost is half-counted if the collector only reads session files.
- A long subagent run leaves the main file silent for more than 10 minutes. That
  splits the block, and the block where the results return has no human event,
  so the supervised time is dropped.

### C-3 · HIGH: most model usage is unpriced
**Evidence:** about half of the 162k assistant lines come from `claude-opus-5`,
`claude-opus-5-5`, `claude-sonnet-5` and `claude-fable-5-1`. None of these are
in the `pricing-reference.md` snapshot. There are also 831 `<synthetic>` lines.
The spec's cost formula leaves out the cache-read and cache-write multipliers,
and cache tokens dominate here: one sample turn had 42,840 cache-read tokens
against 2 input tokens.

**Root cause:** the price table was copied from a stale snapshot, and the
formula came from the doc rather than from `generate.py`'s `entry_cost`.

**Impact:** "unknown model → unpriced" silently drops about half of AI cost, and
the rest is mispriced.

### C-4 · HIGH: cost de-duplication has to be global
**Evidence:** 4,875 `uuid`s and 1,121 assistant `message.id`s appear in more
than one file. Resumed and forked sessions copy history into a new file.

**Root cause:** the spec says to de-duplicate "per `message.id`" but doesn't set
the scope. The Python report de-duplicates on `(sessionId, message.id)`, and a
forked copy can carry a different `sessionId`.

**Impact:** cost is overcounted. Time happens to survive because the interval
union absorbs identical copies, but the evidence counts in narratives are
inflated.

### H-1 · HIGH: the SessionStart nudge would stall every session
**Evidence:** a full scan takes 9.2 s with a warm cache. `cleanupPeriodDays` is
3650, so the corpus only grows.

**Root cause:** `nudge` derives the summary from transcripts when it runs.

**Impact:** 9 s or more of latency on every session start, getting worse over
time.

### H-2 · HIGH: allocation across unregistered repos misbills
**Root cause:** the overlap union only covers registered client repos. Time in
opchain or personal repos isn't part of the union.

**Impact:** a client agent block running while you prompt in an unregistered
repo bills the client for time you spent elsewhere.

**Related:** "most recent human event wins" gives all of a parallel agent run to
whichever session you touched last. That's systematic but undocumented.

### H-3 · HIGH: the block model's inflation is large and unbounded
**Evidence:**

| Model | Hours over the corpus |
|---|---:|
| Block model | 157 |
| Human cadence | 90 |

The block model is 74% higher. 13 billable blocks cross midnight.

**Root cause:** agent runtime is included and `agent_tail_cap_minutes` defaults
to off. Several non-message entry types also carry timestamps and would stretch
blocks if "all events" is taken literally: `attachment` (60k), `system` (hook
stamps), `pr-link`, `queue-operation` and `file-history-delta`.

### M-1 · MEDIUM: branch→matter rarely matches in your workflow
**Evidence:**
- Worktree branches are auto-named `claude/<slug>-<hash>`.
- 2,555 lines have `gitBranch: "HEAD"` (detached).
- 130 sessions change `cwd` partway through.

**Impact:** most time falls into `general`. However, there are 3,387 `pr-link`
entries, which give a PR to ticket mapping for free.

### M-2 · MEDIUM: prompts typed while the agent is busy
**Evidence:** 2,716 `queue-operation` enqueue entries.

**Impact:** a prompt typed while the agent is busy is recorded as a user line
only when it's dequeued. The moment of engagement is the enqueue.

### M-3 · MEDIUM: the transcript format is internal and drifting
**Evidence:** 27 entry types, many without timestamps. `origin` and
`promptSource` are missing in older versions. 219 files are not in timestamp
order.

**Impact:** a parser without a canary breaks silently.

### M-4 · MEDIUM: the nudge leaks billing data into model context
**Root cause:** SessionStart hook stdout goes into the model context.

**Impact:** client names and rates get written into every session's transcript.

### M-5 · MEDIUM: concurrent ledger appends
**Root cause:** parallel `draft` runs append to the same `ledger.jsonl`.

**Impact:** lines longer than PIPE_BUF (4 KB) can interleave.

### M-6 · MEDIUM: config durability
**Root cause:** the ledger now lives outside the repo, but `billing.yaml`, which
holds the rate and the matter rules, is gitignored inside the repo.

**Impact:** deleting the clone loses the config while the ledger survives.

### M-7 · MEDIUM: rounding compounds with per-worktree matters
**Root cause:** each matter-day is rounded up to 0.25h separately.

**Impact:** with auto-named branch matters, that adds up to 14 minutes per
matter per day.

### L-1 · LOW: cloud and web sessions aren't visible
Sessions on claude.ai/code or cloud agents leave no local transcript, so success
metric #3 ("no silent gaps") can't detect them.

### L-2 · LOW: success metric #1 is circular
Measuring drift between the draft and the approved hours rewards anchoring to
the draft.

### L-3 · LOW: checkpoint `generated_files` entry is a glob
The entry `docs/plans/time-tracking/spec/{00,…}-*.md` is a brace glob, not a
path, and `checkpoint:doctor` can't resolve it.

## Punch list (fix order)

Every item below is a spec change, not code. Items 1–4 must be done before
design.

1. **C-1 · Classifier.** A line counts as human only if:
   - `origin.kind == "human"`, **and**
   - the content doesn't match a machine-envelope denylist: `<task-notification`,
     `<scheduled-task`, `<ci-monitor-event`, `<cross-session-message`, a message
     that is only a system reminder, `<local-command-stdout`,
     `isCompactSummary`, `isVisibleInTranscriptOnly`.

   User-initiated envelopes count as human: `<command-name>`,
   `<command-message>`, `<bash-input>`, `<create-pr-command>`.

   Answers are the `tool_result` lines whose id matches an `AskUserQuestion` or
   `ExitPlanMode` call.

   Anything unknown is quarantined as non-billable and reported. Add a
   **UserPromptSubmit hook** as the primary human-event signal, with the
   transcript as backfill. Build the golden fixtures from these real shapes.
2. **C-2 · Subagents.** Collect from `<session>/subagents/*.jsonl` for cost.
   Treat subagent activity as session activity for block continuity only, never
   as a human event.
3. **C-3 · Pricing.**
   - Take the current table from oc-claude-api and match on model-family prefix.
   - Skip `<synthetic>` lines.
   - Port the cache multipliers from `generate.py`.
   - Show the unpriced share on every disbursement line, and block `approve` for
     a disbursement whose unpriced share is above 0.
4. **C-4 · De-duplication.** Key cost on `message.id` globally, taking the
   maximum of each field. Key events on `uuid` globally.
5. **H-3 · Blocks.**
   - Set an explicit list of entry types that extend a block: `user`,
     `assistant`, plus subagent `assistant` lines.
   - Split blocks at local midnight.
   - Default `agent_tail_cap_minutes` to 30.
   - Show the block-model and human-cadence totals side by side in review for
     the dogfood period.
6. **H-1 · Performance.** Use an incremental cursor per file (inode, size,
   offset) in `~/.opchain/time/cursor.json`. `nudge` reads only the derived
   cache and never scans transcripts. Put a time limit of 500 ms on the hook.
7. **H-2 · Scan scope.** Scan all projects. Unregistered repos take part in the
   union as a non-billable "internal" bucket. Document the allocation rule and
   offer `overlap: split-even` as an alternative.
8. **M-4 · Nudge output.** Emit the nudge as `systemMessage` JSON, which the user
   sees but the model doesn't, and show only the current repo's client.
9. **M-1 · Matter precedence.** Try sources in this order:
   1. checkpoint `pm_refs`
   2. `pr-link` → PR → ticket
   3. branch rules
   4. `general`

   Resolve `HEAD` through the per-event `cwd` and the reflog at that time.
10. **M-6 · Config location.** Move `billing.yaml` (rate, rules) to
    `~/.opchain/time/<client>/`. The repo holds only a `client:` pointer, or
    none, since the registry maps repo → client.
11. **M-2 · Queued prompts.** Use the `queue-operation` enqueue time as the
    human event; `remove` cancels it.
12. **M-3 · Format canary.** Record per-run counts of unknown entry types and
    envelopes plus the `version` range. `verify` fails when the unknown share
    exceeds 1%. Sort each file's events after parsing.
13. **M-5 · Ledger lock.** Take an `O_EXCL` lockfile around appends.
14. **M-7 · Rounding scope.** Make the rounding scope configurable
    (`matter-day` | `client-day`), and show how many minutes rounding added.
15. **L-1, L-2 · Metrics.** Add a manual-entry verb for cloud-session work.
    Replace metric #1 with a weekly spot-check of 3 random entries against git
    and the transcript.
16. **L-3 · Checkpoint.** Replace the glob with the 8 explicit paths.
