## B. Enforcement at chokepoints (Track E, oc- catalog, lockstep 2.0.4 → 2.1.0)

- **Enforcement map** in `orchestrator.md` §3: where each skill-to-skill edge is
  held and by what (commit, PR, deploy, release, spec, security). #608.
- **Tool-named invocation form** replaces "read that skill's SKILL.md" in every
  handoff (72/72 vs 80/143 for prose); context in args, acceptance checks as
  data. #608, #656.
- **oc-bug-check bypass** is `/oc-bugcheck bypass` + `OPCHAIN_BYPASS=1` with an
  `Opchain-Bypass:` trailer; bare `--no-verify` is recorded by `post-commit` and
  refused by `pre-push`; INCONCLUSIVE is retried, not bypassed. #608.
- **oc-git-ops:** refuses `/oc-commit` in an unenrolled repo; binds pre-PR
  evidence with `checkpoint.mjs handoff`; sync order bind → push → PR; new
  **`/oc-merge <pr>`** verb. #608, Unreleased.
- **oc-app-architect:** `scaffold-spec.mjs` stubs for `spec/01…10`, evaluator
  spawn template, `ux_eval_ref` / `security_review_ref`, delegated lanes. #608.
- **oc-code-auditor:** `/oc-audit diff --read-only <range>`. #608.
- **oc-deploy-ops:** consumer deploy wrapper (`templates/deploy.mjs`);
  **BREAKING: production requires `--prod`.** #608.
- **oc-update:** plugin discovery in `doctor` (S1 #612), keeps enabled
  project/local plugins current (S2 #615), `--with-plugins` + duplicate guard
  (S3 #617); cross-version install proof (#607). S4 not built.
- **Navigation rule:** top navigation only, never a sidebar; release gate row. #590.
- **A skill invoked with a step skips the welcome.** Unreleased.
- **Legacy commit gate checks the repository the commit lands in** (GATE-12). #584.
