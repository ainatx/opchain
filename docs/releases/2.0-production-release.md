# Opchain 2.0.0 production release

Release date: September 14, 2026. The maintainer explicitly requested production
promotion and the release tag after reviewing staging at `1cf060a`.

## Included

The 36-skill shared runtime, verified 1.9.2 baseline, simulation repair `9176f02`,
Slate and Emerald design including PR #490, refreshed comparison, 15 demos and
the copyable upgrade prompt. Learning remains opt-in and requires configured
provider access and an external reviewer. Checkpoint wire remains 1.1.

## Integration and validation

The runtime alignment imported the reviewed `93dc854` baseline as file content.
This release reconciles that already integrated history with `origin/main` at
`3ed39a4`, preserving the tested 2.0 code and current checkpoint state. The only
new main content is archived release evidence and monitoring runbook guidance.
The unused preview banner component and preview marker are removed for the authorized release; its deployment guard
remains and is tested in an isolated marked fixture. The catalog changelog and
site now record the release date.

Staging at `1cf060a` passed the normal commit and deploy gates, live hardening,
smoke checks and 47 browser checks. The release commit must earn fresh candidate
and review evidence before it is merged, tagged and deployed. Final tag and live
identities will be recorded after those operations.

## Validation limits

The four simulation product findings are fixed and verified. The scripted demos
are examples, not model results. Authentic provider improvement evidence and
native-host acceptance have not been completed in this task. External reviewer
setup is required for each installation. Wire 1.2 migration and the repository
split remain future work. None of these items is recorded as a passing check.
