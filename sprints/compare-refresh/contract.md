# Compare refresh contract

## Deliverables

- A separate typed comparison catalog covering opchain and 12 current alternatives across all original dimensions plus product type and retained learning.
- Every cell has at least one primary-source citation, including cells added by the client picker. Documented limitations are qualified; no unmeasured winner badges.
- Freshness date and methodology distinguish a documentation review from hands-on benchmarks, workflow frameworks from agent hosts, pricing from usage, and shipped opchain from planned 2.0.
- Preserve table grouping, theme tokens, selection persistence, keyboard access and horizontal scrolling. Only opchain is pinned; provide workflow and coding-agent presets.
- Durable research notes and evaluator evidence.

## Verification

1. Catalog integrity: complete feature coverage, valid source references, unique IDs, safe citation URLs, valid preset selections.
2. Browser: citations in initial HTML and after selection; all competitors reachable; selection cap/reset/persistence; corrupt, duplicate and obsolete saved IDs recover safely; no-JS table usable.
3. Responsive and accessibility: 375/768/1280px, no page-level overflow, visible focus, named table/scroll region, automatic accessibility scan in light and dark modes.
4. Run existing unit suite, Astro type check, site build and appropriate browser regression tests. No new tests for static wording; tests protect citation/picker behavior.

Use direct source links with descriptive accessible names and a source index. Review against this contract with oc-app-architect and the oc-ux-engineer attach rubric.
