# v2.1 short real-use gate (owner scoped 2026-10-23)

Goal: run each of the ten skills once on a small real task. About 15–30 minutes each, roughly 4 hours in total, and you can split it over days.
Care and vendor-eval are in scope for the gate. The short versions are below. A full care month stays a follow-up (2.1.1).

Rules for every run:
- Use real work, but keep client materials out of Git. Work in a scratch folder outside `~/repos/opchain` or in the client's own repo.
- After each run, write 3 lines in `~/opchain-real-use.md` (outside the repo): skill, what you did, verdict (worked / worked with fixes / blocked) plus anything surprising. I turn these into the evidence record. Do not paste client names or prices.
- "Blocked" or "worked with fixes" goes to me as a bug. I fix it before the cut.

| # | Skill | Short real task (15–30 min) |
|---|---|---|
| 1 | ow-start | One real intake call (you already planned three). Run it start to finish and let it write the intake record. |
| 2 | ow-build-plan | Turn that intake into a plan up to the quote step. No signing needed. |
| 3 | ow-build | Run the first build step of a real small job (or a throwaway repo). |
| 4 | ow-uat | Run acceptance on a real finished piece: freeze, test, sign-off record. |
| 5 | ow-research | Ask one real question you actually need answered. Check that the sources are listed and gaps are admitted. |
| 6 | ow-documentation | Run it on a real project to produce one handover doc. |
| 7 | ow-handoff | Run `-start` on a finished job to produce the handoff and care-start file. Stop before sending anything. |
| 8 | ow-draft | Draft one real client message or proposal section. Decline the send at the approval step. |
| 9 | ow-care | Short version: start a care engagement from the ow-handoff file and log one real request. The full month waits. |
| 10 | ow-vendor-eval | Short version: run a real small vendor choice you actually face (two or three options). Take it through score and recommendation. |

Calls 2–3 may reuse the same job as 1. Run 7 can use the job from 3–4, which saves setup.

Send me the file when you finish, or after any "blocked" run, so I can fix before the next one.
